EcoCharge AI — Project Submission Package

Included files:
- EcoCharge_AI_Project_Presentation.pptx: project presentation
- app.py: Python Streamlit source code
- EcoCharge_AI_Dashboard.html: standalone browser dashboard
- requirements.txt: Python dependencies
- example_results.csv: illustrative calculation output
- README.md: setup and usage notes
- PPT_source_code_note.txt: note for presentation context

Important status note:
This is a software prototype using user-entered illustrative assumptions. The HTML dashboard should be opened and tested locally before claiming a successful demonstration. The prototype does not yet contain a trained AI forecasting model, live data integration, or real charger control. Example cost and CO2 figures are not measured real-world savings.

For GitHub, create a public repository and upload the source files (app.py, EcoCharge_AI_Dashboard.html, requirements.txt, README.md, example_results.csv). The PPT can be uploaded too if you want the repository to include the presentation.
